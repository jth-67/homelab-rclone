HomeLab rclone

Google Drive file transfers for personal HomeLab workflows.

HomeLab rclone uses rclone to transfer and synchronize selected workflow files between the owner's Google Drive account and the owner's systems. It is maintained for the owner's personal use.

How it works

01 / CONNECT

Authorize through Google

The owner connects Google Drive using Google's authorization flow and reviews the permissions requested.

02 / TRANSFER

Run configured workflows

rclone carries out the file transfers and synchronization operations selected by the owner.

03 / CONTROL

Manage access and copies

The owner manages stored copies and can revoke the Google connection at any time.

Access and privacy

The Google authorization grant determines the integration's permissions. Selecting particular files or folders for a workflow does not itself restrict that grant.

Read the privacy policy for information about data use, storage, and removing access.

This website is public documentation. It does not request Google sign-in or access to Google Drive, and it has no file-upload form.

Project and contact

The project is maintained by jth-67. General questions can be raised in the public GitHub repository. Do not post credentials, private file contents, or personal information there.
